# Excel-Assignment1-Data-Exploration

# Overview
This Assignment focuses on exploring a product dataset using Microsoft Excel.

Objectives:

* Calculate the total, count, and average price of products.
* Identify the minimum and maximum product prices.
* Categorize products based on their prices using the IF function.
* Analyze product data using SUMIF and COUNTIF.
* Extract information from Product IDs using LEFT, RIGHT, and MID functions.

  TOOLS USED
  * Microsoft Excel
  * Excel formulas and functions
 
  CONCLUSION:

  This Assignment helped me practice essential Excel functions used in data exploration. It strengthened my understanding of basic data analysis and provided practical experience in working with dataset.
